# 🛒 연관 분석 실험실

고등학교 「데이터 과학」 **연관 분석 모델의 개념**을 시뮬레이션으로 직접 만져 보며 배우는 웹앱입니다.

## 학습 목표
- 데이터 간의 관계를 분석할 수 있다.
- 데이터 간의 상호 연관성을 파악하고 결과의 의미를 해석할 수 있다.

## 화면 (2차시 · 탭 5 · 카드 24)
처음 열면 **입장 페이지**에서 차시를 고릅니다. 고른 차시의 탭과 카드만 보이고, 맨 위 [↩ 차시 고르기] 로 언제든 돌아갑니다.

| 차시 | 범위 |
|---|---|
| **1차시** 연관 분석과 세 가지 지표 | 💡 생각 열기 → 📐 세 가지 지표 → 🔎 규칙 찾기의 「실습 정리표」 → 📄 1차시 정리 (카드 15) |
| **2차시** 연관 규칙 찾기와 Apriori | 🔎 규칙 찾기의 「연관 규칙 탐색기」·「좋은 규칙 고르기」 → 🧮 Apriori → 📄 2차시 정리 (카드 9) |

넓은 화면에서는 카드 한 장이 화면 하나라 **스크롤이 없습니다.** ← → 키로 넘깁니다.

| 탭 | 카드 |
|---|---|
| 💡 생각 열기 | 추천의 비밀(가상 쇼핑몰 장바구니 → 함께 산 상품 추천) / 연관 분석이란?(정의 빈칸·분석 흐름·가게 지도·궁금증 카드) / 어디에 쓰일까?(활용 사례 6 — 규칙의 차례와 까닭) / 연관 규칙의 표현(문장에서 선행 찾기·방향 바꾸기·선행과 후행) |
| 📐 세 가지 지표 | 세 가지 질문 / 동시 구매표(빈칸 15) / P(A)(영수증을 보며 세기) / P(A∩B)(벤 다이어그램의 겹친 곳) / 지지도 / 신뢰도 / 향상도 (A·B 를 골라 영수증·벤 다이어그램·계산 흐름, 「삼각김밥 → 사이다」 직접 계산, A⇄B O/X) |
| 🔎 규칙 찾기 | 실습 정리표 / 연관 규칙 탐색기(산점도·최소 지지도·최소 신뢰도) / 좋은 규칙 고르기 |
| 🧮 Apriori | 왜 Apriori?(조합 폭발 그래프) / 트랜잭션과 항목 집합 / 단계별 시뮬레이터(후보 직접 세기 · 가지치기) / 햄버거 가게 규칙 |
| 📄 정리 (차시마다) | 확인 문제(1차시 10 · 2차시 5) / 핵심 정리 빈칸(1차시 7 · 2차시 5) / **그 차시의 학습 내용 PDF 내려받기**(1차시 A4 5쪽 · 2차시 4쪽, 내 활동 결과 포함 — 2차시에서는 두 차시를 한 파일로도 받는다) |

- **서술형 칸**은 띄어쓰기를 빼고 10글자 이상 쓰면 그 아래에 예시 답이 힌트로 열립니다.
- **화면 크기**: 창 비율이 바뀌어도(화면 분할 등) 위아래·좌우에 검은 띠가 생기지 않도록 화면이 창을 꽉 채웁니다.
  세로로 긴 창에서는 나란히 놓인 칸을 위아래로 쌓고, 휴대폰 세로 화면에서는 위에서 아래로 자연스럽게 스크롤합니다.

## 사용 방법
1. `dist/index.html` 을 더블클릭하거나 배포 주소를 엽니다(인터넷 없이도 열립니다).
2. 입장 페이지에서 오늘 할 차시를 고르고, 탭과 카드를 차례로 넘기며 활동합니다. 마친 활동에는 ✔ 가 붙습니다.
3. 1차시가 끝나면(또는 수업이 도중에 끝나면) [💾 다음 시간에 이어하기] 로 기록이 담긴 HTML 파일을 받아 둡니다. 2차시에 그 파일을 열면 기록이 이어지고,
   차시마다 끝에 [🏁 N차시 완료] 로 그 차시의 PDF 를 받습니다(2차시 정리 탭에서는 1·2차시를 한 파일로도 받을 수 있습니다).
   공용 컴퓨터라면 끝나고 화면 맨 아래의 [🧹 내 기록 모두 지우기] 를 누릅니다.

## 개발
```bash
npm install
npm start            # 개발 서버
npm test             # 계산·수업 자료 수치 시험
npm run check:syntax # 소스 전수 점검
npm run build        # dist/index.html 한 파일로 빌드 + 빌드 점검
```
Vite + 바닐라 JS. 그래프는 직접 그린 SVG, PDF 는 html2canvas + jsPDF(앱 안에 함께 묶음).
